# Design rationale — AX1S_TEAM

Сайт собран как одна среда с камерой и сценарием, а не как набор секций с декоративным WebGL. Сюрреализм переведён в механики, не в цитаты картин.

## Референсная система (логика, не копии)

| Источник | Принцип | Механика на сайте |
| --- | --- | --- |
| Дали, текучесть времени | форма как вещество | shader-melt реликвии по скроллу (`uMelt`) |
| Дали, двойственность света | ночная сторона поверхности | drag сдвигает ключ; сущность «ночь» инвертирует Lambert |
| Дали, контролируемый хаос | взрыв и возврат | particle burst при смене сущности, сборка частиц в конце скролла |
| Магритт, природа изображения | объект меняет сущность | tap/click циклит песок / алый / ночь / осколок |
| Магритт, подмена масштаба | горизонт врёт | camera path: синус по X/Z, приближение, lookAt на реликвию |
| Магритт, фрагментация | сборка из осколков | Dust разлетается и стягивается к кости |
| Магритт, сокрытие | progressive disclosure | intro-занавес, hero stagger, scroll-reveal секций |

## Четыре продакшн-механики

1. **Scroll-driven camera path.** Lenis + ScrollTrigger пишут `world.scroll` 0..1. Камера идёт по кривой вокруг реликвии. Мышь добавляет параллакс, не ломая путь.
2. **Morph / текучесть.** Один icosahedron, vertex displacement: droop по Y, noise, fold от `uEssence`. Нет смены меша — одна кость, разные состояния.
3. **Drag-объект.** Hitbox в герое (DOM, не canvas) двигает свет и ориентацию. Клик без движения меняет сущность и запускает burst.
4. **Particle burst / сборка.** Точки живут на сфере вокруг реликвии. Burst раздувает радиус; в конце страницы `assemble` стягивает облако обратно.

## Типографика и палитра

- Display: Cormorant Garamond italic — литературный, не «AI Unbounded + Manrope».
- Body: IBM Plex Sans с кириллицей. Mono: IBM Plex Mono для меток.
- Палитра: void `#05060a`, abyss `#0b1020`, sand `#cbb79a`, gold `#b08d57`, scarlet `#c23b2e`. Контраст CTA золото/песок на void > 4.5:1 для крупного текста.

## Юзабилити против вау

- Canvas `pointer-events: none`. Навигация, CTA и форма всегда в DOM.
- Hitbox реликвии не перекрывает заголовок и ссылки.
- `prefers-reduced-motion` отключает Lenis, intro, 3D, lock скролла.
- Слабые / reduced: poster-градиент той же композиции.
- Кастомный курсор только при `pointer: fine`.

## Почему не отдельные 3D-виджеты

Skill-cloud сцена убрана. Одна реликвия на весь скролл несёт бренд: логотип-морф в шапке, сущность в хинте, свет в кейсе Night Shade. 3D ради 3D отсутствует.
