# AX1S_TEAM — Сюрреалистический манифест цифровой студии

Интерактивный веб-сайт премиальной digital-студии **AX1S_TEAM** на Next.js 16 (App Router), Three.js, React Three Fiber, GSAP и Lenis, выполненный в эстетике сюрреализма (Сальвадор Дали и Рене Магритт) со сквозным жидким 3D-блобом по образцу **[Blobmixer от 14islands](https://blobmixer.14islands.com/)**.

## ⚡ Особенности реализации

- **Сквозная 3D-сцена (`fixed inset-0`)**: единый WebGL-канвас на весь лендинг, объект плавно сопровождает пользователя при прокрутке от первого экрана до контактов.
- **Физика вязкой жидкости (Blobmixer Liquid Physics)**:
  - **Squash & Stretch**: упругое вытягивание вдоль вектора движения с сохранением объёма при быстром скролле.
  - **Поверхностное натяжение (Motion Roundness)**: при движении блоб сглаживается в идеальную каплю, а в покое раскрывает сложную геометрию.
  - **Поверхностная рябь (Ripples)**: бегущие микроволны на нормалях при перемещении.
  - **Осевое вращение**: оборот вокруг вертикальной оси $Y$ при прокрутке страницы.
  - **Интерактивный Drag**: упругое перетаскивание курсором с пружинным возвратом Гука.
- **4 сюрреалистические морфологии**:
  1. *Текучесть* (тающая капля Дали);
  2. *Подмена* (яблоко Магритта);
  3. *Сокрытие* (кристалл-желе Магритта);
  4. *Метаморфоза* (пульсирующая 5-лепестковая звезда Дали).
- **Продвинутый GLSL-шейдинг**:
  - Аналитический расчёт нормалей в касательном пространстве (Tangent-Space Normals) методом конечных разностей без артефактов и заломов.
  - Тонкоплёночная радужная иридесценция с хроматической аберрацией.
  - Двухкомпонентный блик (Dual-Lobe Clearcoat): сатиновое рассеивание + зеркальный глянец лака.
  - Подповерхностное рассеивание (Subsurface Scattering, SSS).
  - Процедурные софтбоксы студийного окружения без тяжёлых HDRI-текстур.
- **Реактивная типографика**: при сближении с 3D-блобом заголовки динамически переключаются в контрастный сияющий белый цвет с защитной обводкой и неоновой аурой.
- **Поддержка доступности и слабых устройств**:
  - Полный учёт `prefers-reduced-motion` (автоматическое отключение и замена на статический постер).
  - Эвристика слабых GPU/CPU (`useDeviceTier`) с динамическим снижением детализации сетки и DPR.
  - Автоматическая пауза рендера при скрытой вкладке браузера (`visibilitychange`).

## 🚀 Быстрый старт

### Требования
- Node.js 18.18+ или 20+
- npm / yarn / pnpm / bun

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Проверка типов TypeScript
```bash
npm run typecheck
```

### Сборка для продакшена
```bash
npm run build
npm run start
```

## 📁 Структура проекта

```
src/
├── app/
│   ├── layout.tsx         # Корневой макет, шрифты, метаданные, Schema.org

├── components/
│   ├── layout/            # Header, Footer, Providers
│   ├── sections/          # Hero, Manifest, Work, Practices, Process, Studio, Contact, Faq

│   │   ├── blob-shader.ts # Вершинный и фрагментный GLSL-шейдеры блоба
│   │   ├── World.tsx      # Главная сцена: меш блоба, спутники, свет, камера
│   │   ├── WorldCanvas.tsx# Полноэкранный WebGL-слой, синхронизация со скроллом

├── data/                  # Тексты, кейсы, манифест, услуги, FAQ
└── lib/                   # Хранилище world-store, Lenis, GSAP, Web Worker, хуки
docs/
├── TUTORIAL.md            # Полный учебник по созданию сайта и анимации
├── design-rationale.md    # Обоснование дизайн-системы
└── seo-report.md          # SEO и доступность
```
